## 🚀 Featured Flagship Ecosystems

### 🛡️ [The Valtiss](https://thevaltiss.com)
> National student leadership citation archive and digital credential verification registry.

- **Purpose:** Standardizes and immutably archives student leadership records, SRC executive tenures, and institutional honors across Ghanaian tertiary institutions.
- **Key Features:** Unique prefix encoding (`VT-GH-`), custom verification QR routing, automated multi-channel notification via Cloudflare Email Routing, and cross-border billing integration via Paystack.
- **Core Tech:** Next.js, TypeScript, Tailwind CSS, Node.js, Vercel, Cloudflare DNS/Email, Paystack API.

---

### 🎓 [SCode Academic AI (COE Pasco)](https://scode-coepasco.online/)
> Flagship learning repository and automated exam prep engine for Colleges of Education.

- **Purpose:** Centralized repository granting thousands of teacher-trainees direct access to structured past questions, solutions, PDF parsing, and interactive AI tutoring.
- **Core Tech:** Next.js, FastAPI, Python PDF parsing pipeline, Supabase, Tailwind CSS, Vercel.

---

### 🏛️ [Bowiri Traditional Council Digital Heritage Portal](https://github.com/SCodeGit/Bowiri-Traditional-Council)
> Identity tracking, archival governance, and cultural preservation system.

- **Purpose:** Deployed cloud database system for digital identity verification, traditional lineage tracking, and historical archival for the Bowiri Traditional Area.
- **Core Tech:** React, Node.js, KoboToolbox dataset pipeline, Cloud Database Architecture.

---

### 🤖 [SCode AI Models & Quantized Deployments](https://scodegit.github.io/SCodeAI-Models/)
> Dedicated hub for specialized, fine-tuned, and quantized AI models.

- **Deployment:** Tailored for localized offline environments using GGUF quantization (Ollama runtime `qwen2.5-coder`) and cloud interfaces via Hugging Face.
- **Applications:** Powering document indexing, automated academic problem solving, and low-latency spatial intelligence routines.
